11+ years in QA & automation. Now focused on the intersection of AI and quality engineering — building intelligent agents that test, evaluate, and remediate software without human bottlenecks.

### What I'm building

| Project | Description |
|---|---|
| **CLI Cortex** | Two-layer AI agent (Gemini + Claude + GraphRAG) across 24 CLI plugins. Analyses PRs, detects cross-plugin impact, generates Java E2E tests, raises test PRs. Reduced a 2–4 hr workflow to under 2 minutes. |
| **MCP Agent Eval Suite** | Evaluation framework for live LLM agents across 28 MCP profiles. Covers grounding, tool selection, multi-step chaining, prompt-injection resistance. LLM-as-a-judge scoring + hard quality gates in CI. |
| **SnykrAI** | Autonomous security remediation for 80+ repositories. Scans Snyk vulnerabilities, generates dependency fixes via Claude (Gemini fallback), validates through build and test gates, raises draft PRs — zero manual intervention. |
